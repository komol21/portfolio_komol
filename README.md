# Komol Krishna Paul — Personal Portfolio Website

A modern, responsive, and recruiter-focused personal portfolio website for **Komol Krishna Paul**, Computer Science and Engineering graduate from Independent University, Bangladesh (IUB), and aspiring Data Analyst, Machine Learning Researcher, and Software Developer.

🌐 **Live Demo:** [https://educationmanage.netlify.app](https://educationmanage.netlify.app) (or your deployed Netlify URL)

---

## 🚀 Key Features

* **Modern & Sleek UI/UX:** Glassmorphism card design, dark/light theme toggle with persistent state.
* **Modular Case Study System:** 3-part structured modals covering *Problem*, *What I Did*, and *What Came of It*.
* **Comprehensive Tech Toolkit:** Categorized skill badges across Data Analytics, Machine Learning, Computer Vision, and Web Development.
* **Research & Publications:** Highlights peer-reviewed conference publications in ICEFronT 2026 and FICTA 2026.
* **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
* **Fast & Accessible:** Lightweight vanilla HTML, CSS, and modern JavaScript with no external framework dependencies.

---

## 🛠️ Built With

* **HTML5** (Semantic layout, SEO meta tags, accessible structure)
* **CSS3** (CSS Custom properties, Grid, Flexbox, glassmorphism effects, responsive media queries)
* **JavaScript (ES6+)** (Dynamic project rendering, Intersection Observer animations, modal interactions, theme switcher)
* **Font Awesome 6 & Google Fonts** (Inter & JetBrains Mono)

## 💻 Local Setup & Development

1. Clone this repository:
   ```bash
   git clone https://github.com/komol21/portfolio_komol.git
   cd portfolio_komol
   ```
2. Run a local server:
   ```bash
   python -m http.server 3000
   ```
3. Open `http://localhost:3000` in your browser.
